# SkilliZee Ideathon – Level 2 (web deck)

Next.js slide deck for Ideathon Level 2: Think. Build. Brand. Pitch.

- Slide text: `src/content/level2-data.ts`
- Slides: `src/components/level2/`
- Images: `public/media/level2/` (see `ANTIGRAVITY_IMAGE_PROMPT.md` for the list)
- Reel videos (slide 6): `public/media/level2/videos/`

## Run locally

```bash
cd level-2
npm install
npm run dev
```

## Deploy on Vercel

Create a new Vercel project from this repo and set **Root Directory = `level-2`**.
The Level 1 deck stays at the repo root as its own Vercel project.
